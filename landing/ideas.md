## Idea 1: Military-Editorial Brutalism (Anduril Behance Reference)

**Design Movement**: Swiss International Typographic Style meets Military Command Interface — inspired directly by the Anduril Behance portfolio. Stark, authoritative, zero ornamentation.

**Core Principles**:
1. Absolute typographic hierarchy — Inter 800 for headlines, Inter 400 for body, Geist Mono for all technical/data labels
2. Binary color system — pure black (#000000) and warm cream (#F5F4EF) only, no gradients, no accents
3. Grid-driven editorial layout — vertical column dividers, thin horizontal rules, newspaper-like structure
4. All-caps everywhere except body paragraphs — military/intelligence aesthetic

**Color Philosophy**: The entire page alternates between black sections and cream sections. The cream (#F5F4EF) is warm, not sterile — it evokes aged paper, intelligence dossiers. The contrast between sections creates dramatic visual rhythm. No color accents whatsoever.

**Layout Paradigm**: Full-width sections with internal column grids separated by hairline borders. Asymmetric two-column layouts for content sections. The radar/lattice section uses a 1fr-2fr-1fr grid with empty spacer columns flanking the visualization.

**Signature Elements**:
1. Thin 1px border dividers (both horizontal rules and vertical column separators)
2. Status badges with square corners and thin borders (ACTIVE, MONITORING, LIVE)
3. Geist Mono technical labels with bracket notation like `[ OSINT NEXUS ]` and `[ 2026 ]`

**Interaction Philosophy**: Minimal — hover states are subtle background shifts (rgba overlays). Arrow buttons on career cards invert on hover. No animations, no parallax, no scroll effects. The content speaks.

**Animation**: None. Completely static. The design derives authority from stillness.

**Typography System**:
- Headlines: Inter 800, sizes from 48px to 160px, letter-spacing -0.02em, line-height 0.88-0.92
- Body: Inter 400, 12px, line-height 1.85, letter-spacing 0.03em
- Technical labels: Geist Mono 400, 9-11px, letter-spacing 0.1-0.35em
- Section labels: Inter 400, 10px, letter-spacing 0.35em, uppercase

## Idea 2: Dark Intelligence Terminal

**Design Movement**: Cyberpunk Terminal UI — everything on black, green/amber monochrome accents, scanline effects, terminal-like typography throughout.

**Core Principles**:
1. Full dark mode — no light sections at all
2. Monospace-first typography — Geist Mono as primary font
3. Terminal-inspired UI patterns — blinking cursors, command prompts, ASCII borders
4. Phosphor green (#00FF41) as the only accent color

**Color Philosophy**: Pure black background with phosphor green text creates a hacker/intelligence terminal aesthetic. Information feels classified, raw, unprocessed.

**Layout Paradigm**: Single-column terminal output with fixed-width content blocks. No grid columns — everything flows vertically like a terminal log.

**Signature Elements**:
1. Blinking cursor animations on headings
2. ASCII art borders and dividers
3. `>` command prompt prefixes on labels

**Interaction Philosophy**: Typewriter text reveal on scroll. Terminal-style hover effects.

**Animation**: Typewriter text animations, scanline overlay, blinking cursors.

**Typography System**: Geist Mono for everything. Size hierarchy only through weight and scale.

## Idea 3: Cartographic Intelligence Atlas

**Design Movement**: Vintage cartography meets data visualization — inspired by Cold War-era intelligence maps and NATO tactical displays.

**Core Principles**:
1. Map-centric layout — every section anchored by geographic visualization
2. Sepia/parchment tones with tactical overlay marks
3. Contour lines and topographic patterns as decorative elements
4. Handwritten-style annotations mixed with precise data typography

**Color Philosophy**: Warm parchment base (#F5F0E0) with dark brown (#2C1810) text and red (#8B0000) for active threat markers. Evokes declassified intelligence documents.

**Layout Paradigm**: Full-bleed map backgrounds with overlaid information cards. Asymmetric placement mimicking pinned intelligence briefings.

**Signature Elements**:
1. Topographic contour line patterns
2. Red threat-level markers and classification stamps
3. Handwritten-style coordinate annotations

**Interaction Philosophy**: Map zoom and pan interactions. Hover reveals intelligence overlays.

**Animation**: Subtle pulsing on active threat markers. Slow pan across map backgrounds.

**Typography System**: Mix of serif (for headings — authoritative) and monospace (for data). Body in clean sans-serif.
